# 用語集

本パッチ内の初期表記です。英字欄は照合用の名称で、抽出した文章は収録しません。公式日本語表記として断定せず、ゲーム内の文脈を優先します。

| 照合用名称 | 基本表記 | 使い分け・注意 |
|---|---|---|
| Aidan | エイダン | 主人公。表記を統一する |
| Sunny | サニー | 主人公の恋人 |
| Pinhead | ピンヘッド | 名前として言及される場合 |
| Hell Priest | 地獄の司祭 | 称号・字幕の話者表示。内部キーがPinheadでも名前へ置き換えない |
| Cenobite | 魔道士 | 複数は文脈に応じ「魔道士たち」。一般の魔術師とは区別する |
| Chatterer | チャタラー | 固有名 |
| Butterball | バターボール | 固有名 |
| Fallen | フォールン | 表示名として使われる場合。「堕落した」などの形容詞用法と区別する |
| Lament Configuration | ラメント・コンフィギュレーション | 映画由来の箱の名称。本作の箱と混同しない |
| Genesis Configuration | ジェネシス・コンフィギュレーション | 本作の箱の名称。UIで省略が必要なら文脈が明確な「箱」を使う |
| puzzle box | パズルボックス | 一般的な説明。会話では「箱」も可 |
| Labyrinth | 迷宮 | 異界の呼称。説明が必要な初出に限り「迷宮（ラビリンス）」を検討する |
| Leviathan | リヴァイアサン | 固有名としての言及。単なる巨大生物と混同しない |
| cult / cultist | 教団／教団員 | 集団と構成員を区別。「信者」は信仰に焦点を当てた会話で使用可 |
| ritual | 儀式 | 礼拝、契約、供犠との違いを文脈で保つ |
| offering / sacrifice | 捧げ物／生贄 | 行為・対象・犠牲のどれを指すか確認する |
| suffering / pain | 苦痛／痛み | 数値資源など固有のUI名は別途文脈確認。機械的な同義語置換をしない |
| pleasure / ecstasy | 快楽／恍惚 | 苦痛と対になる感覚を単に「喜び」と弱めない |
| flesh | 肉／肉体 | 生々しい質感と宗教的意味のどちらが重要か判断する |
| salvation | 救済 | 人物の信仰を表す場合。通常の救助と区別する |
| Health | 体力 | ゲージ・回復量・最大値の表記を統一する |
| Suffering | 苦痛 | 箱の能力に使う資源。通常の痛みを語る文章とは区別する |
| Hellchains | 地獄の鎖 | 能力名。操作説明と死亡時ヒントで統一する |
| telekinesis / pyrokinesis | 念動力／発火能力 | 箱の能力の呼称 |
| Unworthy | 選ばれざる者 | 敵の呼称。「資格がない」という一般的な意味とは区別する |
| Embracer | 抱擁者 | 敵の呼称 |
| Sister of Mercy | 慈悲の修道女 | 人物・敵の呼称 |
| Bruno / Charlotte / Marlowe | ブルーノ／シャーロット／マーロウ | アイテム・操作表示・ヒントで統一する |
| banish | 追放 | 対象を消し去り、体力や苦痛を回復する操作 |
| Save Token | セーブトークン | 難易度ヘルレイザーでセーブに消費する。通常のセーブと混同しない |
| inventory / storage | 持ち物／保管庫 | 携行中の物と預けた物を区別する。保管箱は設置物の呼称 |
| attachment / part | アタッチメント／パーツ | 付け替え可能な部品と恒久的な強化部品を区別する |
| damnation | 永劫の責め苦／地獄への堕落 | 文脈依存。単なる悪口と混同しない |
| checkpoint | チェックポイント | セーブそのものと区別する |
| load / continue | ロード／つづきから | メニューの機能に合わせる |
| interact / inspect | 調べる | 拾う・開く・話すなど明確な行為がある場合は具体的に訳す |

Genesis Configurationと主人公・恋人の関係は[ゲーム公式紹介](https://saber.games/hellraiserrevival/)で確認しています。Lament Configurationと魔道士の関係は[原作者公式サイト](https://clivebarker.info/hellraiserb.html)を参考にしています。日本語欄はこのパッチの編集方針です。

その他の人物・道具・能力は、実際の登場箇所と表示名を照合して追加します。内部開発名だけから公開表示名を決めず、未確認の呼称は翻訳データのレビュー情報に残します。
