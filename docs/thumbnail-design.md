# 紹介用サムネイルの制作仕様

日本語化パッチの紹介用に、提供画像を背景とした横長のサムネイルを制作する。

- 表示文字は「日本語化」の４文字とし、画面下半分に大きく配置する。
- 文字はゲームタイトルを参考にした明朝体とし、赤みを抑えた深紅の金属質感、浅い立体感、控えめな縁取りで落ち着いた印象にする。
- 文字の過度な突起・光沢・表面装飾を抑え、字形の読みやすさを保つ。
- 青白い電撃を文字の輪郭と文字間に沿わせる。文字周りの密度と明るさを抑え、背景の電撃と調和させる。
- 血の飛沫や滴を文字とフックの装飾に用いる。
- フック付きチェーンを画面の縁に配置し、人物の顔と文字を隠さない。
- 背景の４人の配置と特徴を保ち、青黒い霧と冷たい光で統一する。
