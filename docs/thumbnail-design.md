# 紹介用サムネイルの制作仕様

日本語化パッチの紹介用に、提供画像を背景とした横長のサムネイルを制作する。

- 表示文字は「日本語化」の４文字とし、画面下半分に大きく配置する。
- 文字はゲームタイトルを参考に、鋭い明朝体の輪郭、深紅の金属質感、明るい縁取りを組み合わせる。
- 青白い電撃を文字の輪郭と文字間に沿わせ、暗い背景でも読みやすくする。
- 血の飛沫や滴を文字とフックの装飾に用いる。
- フック付きチェーンを画面の縁に配置し、人物の顔と文字を隠さない。
- 背景の４人の配置と特徴を保ち、青黒い霧と冷たい光で統一する。

## 保存と確認

原画像、参照素材、生成画像、制作プロンプトは `.local/artwork/issue-51/` に保存する。ゲーム由来の画像を含むため、Git・GitHubおよびパッチの配布物には含めない。

確認対象は「日本語化」の字形、顔の視認性、文字の欠け、電撃・血・フック付きチェーンの反映とする。画像の制作完了は、パッチの通しプレイや公開準備の完了を意味しない。
