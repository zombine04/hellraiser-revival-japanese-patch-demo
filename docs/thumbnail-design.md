# 紹介用サムネイルの制作仕様

日本語化パッチの紹介用に、提供画像を背景とした横長のサムネイルを制作する。

- 表示文字は「日本語化」の４文字とし、画面下半分に大きく配置する。
- 文字はゲームタイトルを参考にした明朝体とし、鮮明な赤色の平面文字にする。立体化、押し出し、面取り、金属光沢は用いない。
- 鋭いセリフと線の太細でタイトルの雰囲気に寄せ、縮小時も４文字を読み取れる大きさと字形を保つ。
- ストア紹介素材を参考に、青白い電撃を文字の輪郭と文字間に沿わせる。細く分岐する放電と控えめな青い光で、赤い文字面を隠さず電撃をまとわせる。
- 今回は血、フック付きチェーン、追加のロゴや説明文を加えない。
- 添付背景の横長の構図、４人の配置と特徴、青い霧と冷たい光を保ち、人物の顔を文字で隠さない。
