# ブルーノの口調調査（Issue #37）

## 結論

エイダンへの説明に敬体が混ざる箇所は、翻訳の揺れである可能性が高い。相手に応じた敬語の使い分け自体は翻訳方針に明記されているが、同じ相手への説明中に切り替える理由は確認できなかった。原作の演技上の意図まで否定するものではない。

今回は調査のみ。翻訳データ、レビュー状態、配布物、ゲームへの導入状態は変更していない。

## 対象と確認方法

2026年9月20日時点のdevelopを基準に、字幕データの話者キー末尾が`_Keller`の220件（第1章40件、第3章87件、第4章5件、第5章87件、話者名1件）を確認した。英語原文との識別情報・原文ハッシュの不一致は0件。原文との対照記録はローカルに保存した。

第1章の独房での会話を中心に、同じ場面に属する他の話者の発言、別の相手への発言、後続章の訳調、翻訳方針と変更履歴を照合した。ユーザーが指摘した具体的な字幕は未特定のため、以下は該当候補についての判断である。

## エイダンへの説明に見られる混在

名前空間は`ST_VO_Mission01`、キー接頭辞は`VX_Mission01_01Prison_CellAwake_`。下表は文章の意味上のつながりに沿って並べたもので、実機の再生順・間・視線を再確認したものではない。

| キー末尾 | 現在の日本語訳 | 観察 |
|---|---|---|
| `Fu1a_Keller` | カササギ君、フラマリオンの版画を知っているかね？ | エイダンへの呼びかけ。常体 |
| `g4Tt_Keller` | もっと多くを求めた末に、世界の果てに辿り着いた男が描かれている | 版画の説明。常体 |
| `sWeB_Keller` | 欲望に駆られた男は世界の裾をめくり、その向こうを覗く。そして宇宙の秘密に、恐怖と驚嘆を覚えるのです | 同じ説明の中で文末だけ敬体 |
| `mbNl_Keller` | 君もまた、その淵に辿り着いたのだよ、カササギ君 | 再びエイダンへの呼びかけ。常体 |
| `2NGi_Keller` | さて、君にはどんな素晴らしい使命が用意されているのだろうね？ | 常体 |

原文の文章上、この説明の途中だけエイダンへの敬意・服従が増す、相手が変わる、明示的な引用や別人の声になる、と判断できる指示は見つからない。芝居がかった講義調を「のです」で表した可能性はあるが、それを意図的な切り替えとして記録した根拠はない。現時点では`sWeB_Keller`を口調の再検討候補とするのが妥当。

## 使い分けとして説明できる箇所

同じ独房の場面には、マーロウを呼ぶ「マーロウ！　ご覧ください！」（`5MeE_Keller`）と、命令に答える「はい、マーロウ。御心のままに」（`enH8_Keller`）がある。これらは宛先が明確で、エイダンへの常体と区別できる。

「次はどうします？」（`XycV_Keller`）、「もうですか？　もっと時間が要る、まだ――」（`vTS2_Keller`）も、同じ場面の指示・準備の会話からマーロウへの発言と読むのが自然。ただし各字幕に宛先のメタデータがあるわけではなく、文章からの推定である。エイダンがその場にいるだけでは、全発言がエイダン宛てとは限らない。

第3章・第5章のエイダンへの呼びかけも「君」「かね」「たまえ」などの常体が基調。第5章のマーロウとの会話では「傷を閉じさせてください」「根づくのでしょう？」「本当に…よろしいのですね？」などがあり、相手に応じた使い分けを裏づける。

別場面の`BedsideManner`でも「変容は繊細な過程です」「そこに芸術が宿るのです」と「楽しんでいるね、子羊よ？」が混在する。ただし同群および関連する`BedsideManner2`にはシャーロットの応答・名指しがあり、これらをエイダンへの口調の証拠には数えない。説明部分を敬体にする傾向を示す補助例にとどめる。

## 方針と履歴

[翻訳方針](translation-guide.md)は、ブルーノを「芸術家としての尊大さと、芝居がかった親しさ」とし、「相手や力関係で敬語が変わることを保つ」と定めている。したがって全発言を一律に常体へそろえる判断は適切ではない。

問題の訳文は字幕追加コミット`c4a87f9`で導入され、該当文を後から変更した履歴は見つからなかった。方針追加と字幕追加のPR説明には人物の口調を確認したという包括的な記録があるが、この一文を敬体にする個別理由は記録されていない。記録がないことだけで翻訳者の意図がなかったとは断定できない。

## 確認の限界

音声の聞き直し、カメラ・視線、実機での連続字幕再生は今回実施していない。原文テキストと翻訳履歴に基づく結論は「意図的と裏づけられず、翻訳の揺れが疑われる」まで。指摘された場面との一致と演技上の切り替えは、修正を行う場合に該当箇所で確認する。
